# Habit Lab
Русский игровой учебный центр: Kotlin + Android, Java, Spring Boot.

21 день, 88 шагов мастерской, 21 проверка понимания, практика общего проекта и игровой сертификат.

После прохождения код-квеста и проверки понимания Android-недели можно скачать проект с собственным принятым ответом для Android Studio. Точный ответ сохраняется в MY_SOLUTION.txt.

Сайт проверяет учебные варианты ответа. Проекты Android компилируются в Android Studio. После входа прогресс хранится в Firebase и синхронизируется между браузерами. В гостевом режиме он остаётся в текущем браузере; доступны экспорт и импорт.

Размещение: GitHub Pages, ветка main, папка / (root). Мастерская работает без библиотек. Для входа и синхронизации загружается Firebase Web SDK.

## Вход и облачный прогресс

Firebase project: `habit-lab-learning`, отдельный Spark-проект владельца курса.
Вход через email/password; Firestore хранит документ `progress/{uid}`.
Синхронизируются достижения, самостоятельная практика, черновики, принятый код,
выбор в тестах, имя сертификата и последний открытый день. Firebase client config
публичный по назначению; доступ определяется `firestore.rules`, опубликованными в консоли.
Читать и записывать документ может только владелец соответствующего Firebase UID.

Гость хранится отдельно в `habitlab-v1`; аккаунты — в `habitlab-user-{uid}`.
Гостевой прогресс переносится только по нажатию отдельной кнопки после входа.
Очередь несохранённых изменений сохраняется локально и отправляется при восстановлении
связи и следующем входе в тот же аккаунт. Перед закрытием страницы дождитесь статуса
«Сохранено в аккаунте», чтобы изменения были доступны с другого устройства.

Слияние использует Firestore transactions: достижения объединяются, а изменённые поля
обновляются отдельно. При одновременном изменении одного поля в двух браузерах
сохраняется последний успешно отправленный вариант. Импорт не удаляет уже полученные
облачные достижения. Оценки учебные и вводятся клиентом; это не система экзаменов.

Проверено: email/password sign-in, восстановление дня и точного кода между Chrome и
встроенным браузером, получение XP в другом браузере, выход в отдельный гостевой режим,
запрет чтения без авторизации и запрет чтения чужого UID (HTTP 403).


## Мастерская v2

Первым открывается код: готовый фрагмент с пропуском, короткая инструкция,
редактор недостающей части, подсказка по синтаксису, проверка и следующий шаг.
Первые два дня содержат по 6 шагов, остальные — по 4. Всего 88 шагов.
Задания чередуют исправление ошибки, дописывание, соединение объектов и функций,
изменение требования и сборку итогового фрагмента. Теория доступна как справочник.

`workshop-engine.js` разбирает ограниченный язык целочисленных выражений и
проверяет их на контрольных входах без eval/Function. Поддержаны арифметика Int,
сравнения, Boolean, if/else, minOf/maxOf и имена свойств из окружения задания.
Это учебная модель, не компилятор Kotlin или Java. Для остальных фрагментов
используется проверка допустимых вариантов с учётом регистра и строковых литералов.

Мастерская хранится в версионированной строке `drafts[day]` вместе с прежним
ответом. Схема Firestore остаётся совместимой с опубликованными правилами.
Существующие достижения, практика, принятые Android-ответы и XP не сбрасываются.
Новый код дня засчитывается после всех его шагов; повторная проверка не добавляет XP.
При редактировании пройденного фрагмента его новая версия требует повторной проверки.

Проверка перед публикацией: все 88 шагов и варианты ответов; ошибочные выражения,
границы фильтра, защита от исполнения произвольного кода; DOM-сценарии ввода,
подсказок, разблокировки, восстановления после перезагрузки, совместимость старого
прогресса и выдача Android-проекта с точным принятым ответом.

## Настоящий Kotlin/JVM и архив кода

`kotlin-runner.js` использует открытый протокол JetBrains Kotlin Playground:
`GET https://api.kotlinlang.org/versions` и
`POST /api/{latestStable}/compiler/run` с `confType: java` (это JVM-цель Kotlin,
не компилятор исходников Java). Точный Main.kt отправляется только по нажатию
кнопки запуска. Вывод и диагностика отображаются как текст, не HTML. Запуск
ограничен 32 000 символами исходника и минутой ожидания на клиенте; отказ сервиса
не считается неправильным учебным ответом. CORS/preflight проверены с Origin сайта.
Android/Compose Android и Spring с зависимостями этот сервис не собирает.

Первые два дня умеют переносить текущий собранный фрагмент в полноценную программу
с main(). Остальные дни также имеют свободный Kotlin/JVM-редактор для основ языка.
Файлы шагов сохраняются отдельно: повторное открытие шага не заменяет отредактированный
файл свежим шаблоном. Последний вывод связан с точным исходником запущенной версии.

В drafts[day] сохраняются workspace-файлы, история запусков с исходниками, последнее выполнение, принятые решения
и история отправленных проверок, начиная с этого обновления. Набранный текст
сохраняется при вводе, отправленные попытки — при проверке. Это синхронизируется
тем же протоколом Firebase, не меняя правила доступа. Общий синхронизируемый прогресс
ограничен 800 КБ UTF-8; при превышении остаётся локальная копия и доступен ZIP,
а статус сообщает, что отправка не выполнена. Лимит браузерного хранилища также
может ограничить очень большой архив. Сайт не видит правки, сделанные только в IDE.

«Скачать мой код и проекты ZIP» доступно в любое время. В архив входят:
progress.json для восстановления, ответы и попытки по дням, собранные фрагменты,
свои Kotlin-файлы в независимых Gradle-модулях, вывод и исходники запусков, а также
Android-проекты с точными принятыми итоговыми ответами. Примеры курса отмечены
reference-example.txt. Отдельные ответы Java/Spring сохраняются как фрагменты,
а не выдаются за автоматически собранный полный сервер.

Сертификат доступен после всех 88 шагов, 21 проверки и 21 подтверждённой практики.
По завершении открывается форма сертификата. Доступны печать/PDF браузера,
скачивание HTML и выгрузка проекта; в полном ZIP также есть certificate.html.
Это игровой сертификат, а не аккредитованный документ.

Проверено: реальное выполнение пользовательского percent без пробелов (30/0/100/0),
реальная ошибка компилятора с координатами, реальная компиляция и выполнение всех
12 сгенерированных Kotlin-программ первых двух дней; DOM-сценарии редактора,
автосохранения, сохранения принятого ответа после ошибки, архива и сертификата;
целостность ZIP и запуск выгруженного Gradle-проекта. Внешний сервис JetBrains
нужен для онлайн-запуска, но сохранение и скачивание кода от его доступности не зависят.
